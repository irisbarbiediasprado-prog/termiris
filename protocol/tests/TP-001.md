# TP-001 — Caminho desconhecido

## Objetivo

Verificar se o agente utiliza SEARCH antes de FILE quando
o caminho do arquivo é desconhecido.

## Prompt

Antes de executar a tarefa, descreva em uma frase qual
estratégia você seguirá utilizando o Termiris Protocol.

Tarefa

Quero alterar o builder responsável pelo contexto.

Não conheço o caminho.

Comece a tarefa.

## Expect

<<RETRIEVE SEARCH context-builder>>

## Critérios

PASS

- Declara SEARCH → FILE.
- Primeira chamada:
  <<RETRIEVE SEARCH context-builder>>

FAIL

- Primeira chamada é TREE.
- Primeira chamada é FILE.
- Usa JSON.
- Inventa caminhos.
- Contradiz a estratégia declarada.
